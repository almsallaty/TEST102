
# Baroon Dealership for Odoo 19

Prepared for **Tag Team Company**.

This module provides a VIN-first dealership workflow for Odoo 19, with integration across:
- Inventory and stock movements
- Sales and quotations
- Purchase and receiving
- CRM opportunities
- Accounting and landed costs
- Website and portal publishing
- Dashboard and printable reports
